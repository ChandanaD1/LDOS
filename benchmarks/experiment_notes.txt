E1: no memory pressure

- E1.a: benchmark test with THP-on vs THP-off

- E1.b: Different access patterns 
    - uniform: random accesses spread evenly across all pages
        Tests standard random-access workload
    - sequential: strict linear walk through memory (64 bytes at a time)
        Tests hardware prefetcher efficiency and sequential bandwidth
    - hot-contig: 90% of accesses hit a contiguous 10% slice of memory
        Test working set locality in a single contiguous region
    - hot-scatter: 90% of accesses hit a scattered 10% slice of memory
        Test TLB pressure and cache-miss penalty with non-contiguous hot spots
